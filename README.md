 🎮 Hangman Game in Python

About the Project
Hangman is a simple text-based word-guessing game developed using Python. The player guesses a hidden word one letter at a time with a limited number of attempts.

 Features
- Random word selection
- Letter-by-letter guessing
- Tracks guessed letters
- Limited attempts
- Win or lose result

 Technologies Used
- Python 3

 How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:


python hangman.py


*Note: Replace `hangman.py` with your actual Python filename if it is different.*

Learning Outcomes
- Python loops and conditional statements
- Strings and sets
- Random module
- Basic game logic

 Project Type
Beginner Python Programming Project
